
# SelfTagger

SelfTagger is an experimental morphological tagger for Russian on multi-head attention.
The idea is to make something like [RNNMorph](https://github.com/IlyaGusev/rnnmorph),
but utilizing multi-head attention instead of LSTM.
Training data is taking from [Sintagrus](https://github.com/UniversalDependencies/UD_Russian-SynTagRus).
